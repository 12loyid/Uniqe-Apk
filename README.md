# Uniqe Design — Premium Graphic Portfolio Android App

Brand: **Uniqe Design** with the supplied UD purple/blue logo.

## Included in this version
- Premium dark purple/blue portfolio UI
- Modern / Classic visual style option
- Home dashboard
- Portfolio showcase with search and categories
- Add / remove projects
- Branding, UI/UX, Illustration, Motion Graphics and Packaging categories
- Add / remove services
- Professional profile and availability status
- Phone, email, Telegram and Adama map links
- Dark / Light mode
- High Resolution / Compressed preference
- sRGB / Adobe RGB preference
- Masonry / Grid / Large Cards / List View options
- Sorting options
- Watermark and download-protection controls
- Resume / image file picker
- Social and portfolio link settings section
- Customer messages/dashboard management section
- Brand controls section for logo/name/colors/slogan
- English / አማርኛ option
- GitHub Actions workflow that builds a debug APK without Android Studio

## Build APK on GitHub
1. Upload this project to a GitHub repository.
2. Open **Actions**.
3. Select **Build Uniqe Design APK**.
4. Click **Run workflow** (or push to `main`).
5. Open the successful workflow run and download the **Uniqe-Design-APK** artifact.

No Android Studio is required on the build machine; GitHub Actions installs JDK, Gradle and Android SDK.
